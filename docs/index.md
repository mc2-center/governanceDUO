# governanceDUO documentation

This is the docs home for the `linkml/` model behind governanceDUO — the DUO-based
governance model, its RDF/knowledge-graph representations, and its Policy Fabric
integration. The root [`README.md`](../README.md) covers the schematic CSV pipeline,
Synapse submission workflow, and a first pass at these same three topics; the pages
here go deeper, with a full auto-generated schema reference and worked examples drawn
from the real files in this repo.

| Page | Covers |
| --- | --- |
| [The LinkML model](linkml-model.md) | Module layout, import graph, DUO term reuse, id→URI minting, `GovernanceMixin`'s conditional rules |
| [Knowledge graph representation](knowledge-graph.md) | The three distinct RDF artifacts this repo produces, why they differ, and how they're validated |
| [Policy Fabric integration](policy-fabric.md) | `policy_fabric.yaml`/`policy_fabric_bindings.yaml`, `PolicyFabricMixin`, and an end-to-end worked example |
| [Schema reference](reference/index.md) | Auto-generated (`make docs`) — every class, slot, enum, and type, each with a Mermaid diagram and, where one exists, an embedded example instance |

## Regenerating

```sh
make docs
```

runs `scripts/prepare_doc_examples.py` (copies `linkml/examples/**/*.yaml` into the
`<ClassName>-<name>.yaml` naming convention LinkML's `gen-doc` needs to embed them)
and then `gen-doc` itself, rewriting `docs/reference/`. The three narrative pages in
this directory are hand-written and are not regenerated by `make docs` — update them
directly when the model changes underneath them.
